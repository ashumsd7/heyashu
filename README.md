## How to add, edit, or fix something

Found a typo? Want a new blog or a notes chapter? Every reader page has an **Edit** (pencil) control next to bookmark, share, and speak.

You can also request a **new notes collection**, or collaborate so your notes get featured.

The full walkthrough lives on the site:

**[How to add / edit — contributing guide →](https://www.heyashu.in/contributing-guide)**

This garden is open source. **Everything ships through GitHub pull requests.** What you see on the website is what lives in this repo.

**[github.com/ashumsd7/heyashu](https://github.com/ashumsd7/heyashu)** · **[Open pull requests](https://github.com/ashumsd7/heyashu/pulls)**
